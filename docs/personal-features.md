# 个人效率功能说明

**版本**: v1.0
**最后更新**: 2026-09-25

本文档介绍 2026-09 版本新增的 9 项个人使用体验功能：命令面板、统一搜索、语义搜索、相关卡片、回顾页、每周 AI 回顾、快捷捕捉、PWA 分享目标、语音速记。

---

## 🎛️ Cmd+K 命令面板

- **桌面端**按 `Ctrl+K` / `Cmd+K`（或点击导航栏搜索框旁的 ⌘K 按钮）唤起
- 空输入时显示快捷动作（写文章/写文档/快速记录/去回顾/切换主题等）
- 输入关键词后跨 **文章 / 卡片 / 知识文档 / 网页批注** 统一搜索，`↑` `↓` 导航、`Enter` 跳转、`Esc` 关闭
- 移动端不弹面板，快捷键直接跳搜索页

## 🔍 统一搜索与语义搜索

- 关键词搜索（原有）：`/search`，LIKE 匹配
- **统一搜索 API**：`GET /api/search/all?q=`，供命令面板使用，按类型分组返回
- **语义搜索**：`/search?source=semantic&q=`，按语义相似度排序，结果带相似度徽标

### 开启语义能力（可选）

语义搜索与「相关卡片」依赖 Embedding 服务，默认未启用，不影响其他功能：

1. 到 [硅基流动](https://siliconflow.cn) 注册获取免费 API Key（免费额度对个人使用足够）
2. 进入后台 **AI 设置** →「Embedding 服务」区块：勾选启用，填入 Key，Base URL 保持默认 `https://api.siliconflow.cn/v1`，模型默认 `BAAI/bge-m3`
3. 点「测试连接」确认可用 → 点「重建向量索引」为存量文章/卡片/文档回填向量（异步执行，量大会需要几分钟）
4. 此后文章、卡片、知识文档保存时自动增量更新向量；也可换用任何 OpenAI 兼容的 embedding 接口（含 OpenAI 官方、阿里百炼）

未配置时：语义搜索 tab 显示引导文案；编辑器的「相关」面板显示配置提示。

## 💡 写作时相关卡片提示

- **知识库编辑器**（React）：右侧栏第 4 个 tab「🔗 相关」，内容超过 200 字后自动列出语义相关的旧卡片/文章/文档
- **博客编辑器**（Quill）：写作助手 dock 第 5 个 tab「相关」，行为相同
- 结果带相似度百分比，点击条目可跳转（卡片无独立页面，显示为纯文本）
- 依赖 Embedding 服务（见上文配置）

## 📅 回顾页 `/review`

登录后导航栏「回顾」进入，包含：

| 模块 | 说明 |
|------|------|
| 写作热力图 | GitHub 风格 7×53 热力图（近 53 周），按写作量分 5 档；含连续记录天数/总量/活跃天数 |
| 那年今日 | 历年今天发布的内容（按本地时区月日匹配，年份越旧越靠前） |
| 随机漫步 | 随机抽取 5 张卡片，「换一批」重抽 |
| 每周回顾 | AI 生成的周度回顾文档列表 + 手动生成按钮 |

首页侧边栏另有「那年今日」小组件（登录可见）。

> 已知说明：热力图「今天」按浏览器时区计算，若浏览器不在东八区可能与服务端日期差一天。

### 每周 AI 回顾

- 汇总近 7 天新增的文章/卡片/批注、idea 积压数、孵化超 14 天的卡片，交给 AI 生成中文回顾，存为知识空间「每周回顾」分类下的文档
- **手动**：回顾页点「立即生成」（异步，约 1 分钟内完成，防重入）
- **自动**：服务器 crontab 加一行（每周一 8:05）：

```cron
5 8 * * 1 cd /path/to/my-blog && .venv/bin/flask weekly-review
```

- CLI 对所有开启 AI 的用户逐个生成；同一周重复执行会返回已存在，不会重复创建
- AI 未配置时会生成纯统计版本的回顾

## ⚡ 快捷捕捉 `/quick-capture`

导航「快捷捕捉」进入：大号输入框 + 「存为卡片」/「存为快速记事」，适合随手记录与连续录入（保存后表单清空留在本页）。

### PWA 系统分享直达

1. 手机浏览器打开站点 → 「添加到主屏幕」安装 PWA（需 HTTPS）
2. 任何 App 里点「分享」→ 选择你的博客 → 直达快捷捕捉页，标题/正文/链接自动预填
3. 技术细节：`share_target` 定义在 `static/site.webmanifest`；`static/sw.js` 为最小 service worker（仅满足安装条件，不做离线缓存）

### 🎙️ 语音速记

- 快捷捕捉页和移动端首页发布面板均有麦克风按钮
- 基于浏览器自带 Web Speech API（免费、无需服务器），支持中文，边说边实时上屏
- 需要 Chrome / Edge / Safari 较新版本，并授权麦克风；不支持的浏览器按钮自动置灰

## 🛠️ 部署注意事项

1. **新依赖 numpy**：生产环境执行 `pip install -r requirements.txt`
2. **数据库迁移**：部署后执行 `python -m backend.migrations`（迁移 009 创建 `embeddings` 表与 embedding 配置列）
3. **前端构建**：`cd frontend && npm run build`（知识库编辑器新增「相关」面板）
4. **静态资源清单**：新增 JS/CSS 后执行 `python scripts/generate_manifest.py`
5. **新增 API** 详见 [API 文档](api-documentation.md) 的「搜索API」「回顾API」「快捷捕捉API」章节

## ❓ 故障排查

| 现象 | 原因与处理 |
|------|-----------|
| 语义搜索显示「未配置 Embedding」 | 到 AI 设置页配置 embedding（见上文） |
| 「重建向量索引」后语义结果仍为空 | 后台任务异步执行中，稍后刷新；看服务日志确认 embedding 配置生效 |
| 手机分享菜单里没有博客 | PWA 未安装（先「添加到主屏幕」）；或非 HTTPS 环境 |
| 语音按钮置灰 | 浏览器不支持 Web Speech API，换 Chrome/Edge/Safari |
| `flask weekly-review` 无输出 | 确认用户已开启 AI 并配置了 API Key；AI 未配置时只对第一个 admin 生成降级版 |
