从 JSON 文件导入

  • ✓ 完整的数据库结构
  • ✓ 保留原始发布日期
  • ✓ 自动创建分类和标签

从 Markdown 文件导入

导入包含 YAML frontmatter 的 Markdown 文件（需打包为 ZIP）

  • ✓ 支持标准 frontmatter 格式
  • ✓ 批量导入多个文件
  • ✓ 保留分类和标签
  • ✓ 自动识别文章元数据

📌 导入说明

  • JSON 格式：使用系统导出功能生成的 JSON 文件
  • Markdown 格式：将导出的 Markdown 文件打包成 ZIP 上传
  • 导入时会自动检测重复文章（通过标题和日期）
  • 不存在的分类和标签会自动创建
  • 文章的作者将设置为当前登录的管理员

⚠️ 注意事项

  • 建议先勾选“仅预检”查看结果；正式导入会使用单事务，失败自动回滚
  • 重复的文章会被自动跳过
  • 如果文章数量较多，导入可能需要一些时间
  • 建议在导入前先清空测试数据
